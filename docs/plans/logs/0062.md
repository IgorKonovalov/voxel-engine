## Phase 1: `vxe-entity`: models, poses in fixed point, and the ray query

- **Start commit:** main 37f6845, branch `plan-0062`.
- **Names, plan to tree:**
  - `EntityHit`'s `axis: u8, positive: bool` (Data shapes) is `face: Option<vxe_world::Face>`,
    `None` when the ray starts inside the voxel, as `vxe_world::Hit::face`.
  - The Q14 quaternion is a newtype `Quat(pub [i16; 4])` (`w, x, y, z`); `PartPose::q` and
    `Pose::root_q` are `Quat`. The product is `impl Mul for Quat`.
  - `Pose::part_point(model, part, local)` takes `local: [i32; 3]` in 1/256 model voxel (the
    pivot's units) and returns `Option<Fixed3>` (`None` for a part past the end or a pose that
    does not fit the model).
  - `PartPose::t` is in 1/256 world voxel, along the parent's turned axes, from the parent's
    pivot (from the root for a part with no parent). `Pose::rest` sets every `t` to zero, so a
    model's rest layout (done-when 4's "rest offset 8 voxels along +x") is carried by the
    child's `PartPose::t`; the `Part` has no rest-offset field.
  - `Model::new` refusals: `ModelError::{NoParts, TooManyParts, ParentCycle, OversizedVolume,
    BadDetail}`. `ParentCycle` is any parent that is not an earlier part.
  - `EntitySet::insert` and `set_pose` return `Result<_, PoseError>`
    (`PoseError::{PartCount, UnknownEntity}`); `remove` returns `Option<(Arc<Model>, Pose)>`;
    `get`, `len`, `is_empty` added.
  - Equal distances are equal exact ray parameters (fractions), not equal rounded `t`.
  - The workspace `Cargo.toml`: `crates/*` already globbed the member; `vxe-entity` is added to
    `default-members` and the dependency table. `clippy.toml`'s wall-clock denial is global, not
    per crate: unchanged.
  - CLAUDE.md "Where things live" gets the `vxe-entity` row.
