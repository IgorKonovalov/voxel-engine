## Phase 2: the four paths headless, quiet, then loaded

**Scope (restated at the start).** No code. Hold A (quiet): cave, showcase, castle, outdoor
headless. Hold B (loaded): cave, castle, outdoor headless under 32 single-thread busy loops.
Hold C (quiet): the cave at `--workers 4` beside the default 8. One table a hold; per streamed
path, quiet against loaded, the ratio of `over_33ms` and the stages that grew. No conclusion.

**Setup common to every run.** Release binary of 0e317422 (`target/release/flythrough`,
`cargo build --release -p flythrough` a no-op at the start); RTX 3080 Laptop, Vulkan, picked by
`--adapter RTX`; 2560 x 1440, FSR 2 at 1.5, Floor; every banner reads `bake thread on`; 16 GiB
scope, exclusive perf lock. Arguments: the plan's tester lines with `--tester` replaced by
`--headless --adapter RTX --bake-thread on`, `--path-mode bench`, `--report DIR`. Load1 is

`p2-loaded-inner.sh`, `p2-run.sh`, `p2-extract.py`, `p2-table.py`; `live/p2/<hold>/<run>/`).

- **Quiet holds** take the lock **per run**: each run first waits outside the lock (up to 4
  min) for load1 at most 2, then takes the lock for that run only. No run started above 2.

  three runs back to back, the loops stopped by PID (a `trap` on exit) after the last; no loop
