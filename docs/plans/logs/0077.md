  `Frame::frame_bytes` adds `MARK_BUFFER_BYTES` (4096).

  marked side's colour (its own first), so the line is drawn on both sides of the silhouette

  edge" reads. Marks apply in the shaded and albedo views; the exposure meter reads the colour
  before the mark. FSR 2's HDR variant mixes in pre-exposed radiance toward `undisplay(colour)`
  (the encode and ACES inverted); the LDR composite mixes the display colour.

  (`dy * 4 + dx`); 27..31 free. The atlas is a storage buffer of 32 x 64 x 64 `u32` (512 KiB),
  bound at group 0 binding 4. A tile pixel with alpha under one half is not drawn; a glyph's
  shadow over a tile pixel mixes it 0.75 toward black, opaque.
- **The icon** (`entities/icon.rs`): the fit is the silhouette's (every solid voxel's eight
  corners projected), not the model's box: the box fit read 16 x 38 pixels for the walker
  (under the 40-pixel bar). Light `(-2, -3, 6) / 7`, a face's shade `96 + 160 cos` 256ths: the
  -x, -y and top faces 141, 164, 232. Walker icon 16 x 40 pixels at (24, 12), 429 solid,
  FNV-1a `0xd6321de901572bc9`; spider (showcase table) `0x494768d9baf02db9`. The tile index is
  the entry's index (an entry past 32 keeps its words). `Run::poll_viewer` takes the icons
  made since the last call, then asks for any entry whose model is new, so an icon asked for
  at the library's build arrives at a later frame.
