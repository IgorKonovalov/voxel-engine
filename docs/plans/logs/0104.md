  1/55 s), the frame, `PollType::wait_indefinitely`, the target read back.
- **The settle and census:** at the start, a device wait every frame, at least 720 frames, then
  until no job is open and no block fades and the census is whole. The census: the distinct
  chunks the lighting pixels' hits lie in, against those `BakeQueue::settled` (the block at its
  tier's count, nothing pending); the coarse blocks among them counted apart.
- **The move:** W along the view with its pitch at 30 voxels/s until the first solid along the
  view ray is 60 voxels off or 2 s; then level along the heading, cut before the first frame
  within 8 voxels (`CLEAR_VOX`) of a solid; to 5 s in all (275 frames, frame 0 at the start). Where
  the fly is under 4 s the level leg's heading turns by the smallest 15-degree step (+ before -)
  that fits 5 s, else 4 s, else none (the camera's yaw is not turned; the eye moves along that
  heading). Then held 165 frames, a 60-degree turn over 40, held 165. A first rule (the turn of
  the longest fly) gave the slot a backward level leg (offset 180) and the canopy -105; its clips
  were discarded and re-rendered (logs `live/anchor/old/`).
- **The stretch filter (clip `T`, no upscaler):** `svet_render::Presenter` (the fly-through's
  present), a full-screen triangle sampling with `FilterMode::Linear` mag and min (bilinear, clamp
  to edge), rendered headless into an `Rgba8Unorm` texture of 2530 x 1378 (`fs_main`; the window's
  sRGB surface takes `fs_srgb`, which round-trips the same values).
- **The format:** RGB frames piped from the rig to `ffmpeg -f rawvideo -pix_fmt rgb24 -s
  2530x1378 -framerate 55 -i - -c:v libx264rgb -qp 0 -preset ultrafast -pix_fmt rgb24

### The runner and the player (verbatim, `live/anchor/`)

`run.sh`:

```bash
#!/usr/bin/env bash
# Plan 0104 Phase 1: the owner's move as clips. Each run holds the perf lock alone.
#   run.sh search [STEP:P,..] the canopy start's search (prints; no clip)
#   run.sh clip SUBJ ARM STEM one clip, e.g. run.sh clip T default T-a
#   run.sh coins             throws the two coins, writes key.txt (the owner is not shown it)
#   run.sh card              the one-pixel checker card, 3 s
#   run.sh all               coins, card, then the five clips in the order T a, T b, C a, C b, S
set -euo pipefail
cd "$(dirname "$0")"
BIN=../bin/gpu_wobble
LOCK=/home/igor/Work/voxel-engine/.git/svet-perf.lock
TEST=clips::reading::the_owners_move_as_a_clip
run_one() { # SVET_CLIP value, log name
  echo "load at the lock request: $(cut -d' ' -f1 /proc/loadavg)" > "logs/$2.log"
  flock "$LOCK" systemd-run --user --scope --quiet -p MemoryMax=16G -p MemorySwapMax=2G -- \
    env SVET_TEST_ADAPTER=rtx SVET_CLIP="$1" nice -n 19 "$BIN" --ignored --exact "$TEST" --nocapture \
    >> "logs/$2.log" 2>&1
  echo "load at the end: $(cut -d' ' -f1 /proc/loadavg)" >> "logs/$2.log"
}
coins() {
  local t c
  t=$(( $(od -An -N1 -tu1 /dev/urandom) % 2 ))
  c=$(( $(od -An -N1 -tu1 /dev/urandom) % 2 ))
  if [ "$t" = 0 ]; then echo "T a=default b=native" ; else echo "T a=native b=default"; fi > key.txt
  if [ "$c" = 0 ]; then echo "C a=default b=ray" ; else echo "C a=ray b=default"; fi >> key.txt
}
arm_of() { # subject letter -> arm from key.txt
  grep "^$1 " key.txt | tr ' ' '\n' | grep "^$2=" | cut -d= -f2
}
card() {
  ffmpeg -hide_banner -loglevel error -y -f lavfi \
    -i "color=c=black:s=2530x1378:r=55:d=3,format=gray,geq=lum='255*mod(X+Y\,2)',format=rgb24" \
    -c:v libx264rgb -qp 0 -preset ultrafast -pix_fmt rgb24 -map_metadata -1 card.mkv
}
case "${1:-}" in
  search) run_one "search${2:+:$2}" "search-${2:-45}" ;;
  clip) run_one "$2:$3:$4" "$4" ;;
  coins) coins ;;
  card) card ;;
  all)
    [ -f key.txt ] || coins
    card
    for s in T C; do
      for l in a b; do run_one "$s:$(arm_of $s $l):$s-$l" "$s-$l"; done
    done
    run_one "S:default:S" S ;;
  *) echo "usage: run.sh search | clip SUBJ ARM STEM | coins | card | all" >&2; exit 2 ;;
esac
```

The clips were made by `run.sh coins`, `run.sh card`, then `run.sh clip` per file with the arm
from `key.txt` (as `all` does). `play.sh` (with `input.conf`: `[ set speed 0.5`, `] set speed
1.0`, `ENTER playlist-next`):

```bash
#!/usr/bin/env bash
# Plan 0104 Phase 2: plays the clips (a video player, no engine, no camera). Enter: next clip;
# Space: pause; . and ,: a frame on and back; [: half speed, ]: normal; s: a screenshot (to
# shots/); i: the player's statistics; q: quit.
set -euo pipefail
cd "$(dirname "$0")"
exec mpv --fs --video-unscaled=yes --loop-file=inf --video-sync=display-resample --interpolation=no \
  --input-conf=input.conf --screenshot-directory=shots --screenshot-format=png \
  card.mkv T-a.mkv T-b.mkv C-a.mkv C-b.mkv S.mkv
```

`play.sh` was not run (it opens a window). Its options were parsed once headless (`mpv
--vo=null --ao=null --frames=10 ... card.mkv`). `live/anchor/check.sh <stem> [s]` repeats the
size, ffprobe, decode and frame-1 checks and extracts the frame read by eye.
