## Phase 1: Clips in `vxe-entity`

- **Start commit:** `plan-0062` at bc80246 (Plan 0062 Phase 1), branch `plan-0063`, a stacked
  lane.
- **Names, plan to tree:**
  - `sample(model, rest: &Pose, clip, tick: u64) -> Pose`. `Part` has no rest offset (Plan 0062
    readings log), so the rest layout is the `t` of the rest pose's part poses; a key's `t` is
    an offset added to it, a key's `q` replaces the rest rotation; a part with no track copies
    its rest `PartPose`. The returned root is the origin, unturned.
  - `Key { tick: u32, t: [i32; 3], q: Quat }`, `Track { part: u8, keys: Vec<Key> }`,
    `Clip::new(&Model, length: u32, looped: bool, Vec<Track>) -> Result<Clip, ClipError>`.
    `ClipError::{UnsortedTrack, KeyPastLength, UnknownPart}` (the plan's three) plus
    `ZeroLength`, `EmptyTrack`, `DuplicateTrack`. Ticks in a track must strictly increase.
  - `Clip::clip_tick(tick)`: `tick % length` when looped, `min(tick, length)` otherwise.
  - Translation between keys: `(a (den - num) + b num) / den` in `i64`, truncated (toward zero).
    Rotation: `quat::nlerp`, the same weights, the second key negated when the dot is negative,
    renormalised with the existing integer `normalise`.
  - `blend(a, b, w: u16) -> Pose`: root, root rotation and every part by the same rules;
    `w` 0 and >= 256 return clones of `a` and `b`; panics on unequal part counts.
  - `Playback { clip: Arc<Clip>, start_tick: u64, rate: u32 }`, `tick_at(now) -> u64`
    (`(now - start) * rate / 256`, floor, 0 before the start), `pose(model, rest, now)`.

## Phase 2: The `.rig` file and voxels from text

- **Names, plan to tree:**
  - `Rig::parse(&str) -> Result<Rig, RigError>`, `RigError { line: Option<usize>, message }`,
    Display `rig line <n>: <message>` (`rig: <message>` for an error with no single line: no
    `vox` line, or the model refusing its parts).
  - `Rig::build(&VoxFile, &dyn Fn(&str) -> Option<MaterialId>) -> Result<RigModel, RigError>`;
    `RigModel { model, part_names, rest: Pose, clips: Vec<(String, Clip)> }`. Parts are put
    parents first (file order otherwise), so a parent may be declared after its child.
  - `Rig::write() -> String` (canonical: `vox`, `rate`, materials, parts, clips; lengths as
    the shortest exact decimal); `Rig::warnings()` (a key pair on one part more than 90 degrees
    apart). `Line` (a line number that is ignored by `==` and `Hash`) keeps lines on parsed
    statements for build errors without breaking the round trip.
  - Grammar beyond the plan's sample: `key ... move x y z` (an offset from the rest place);
    `at` and `move` are in the parent's model voxels (the part's own for a root part) and are
    divided by that detail at build, rounded half away from zero; `part` keywords in any
    order; `detail` defaults to 1, `rate` to 30; degrees within +-3600.
  - Several `rot` on a key: `key_rotation` is the product `r1 * r2 * ...` in written order.
  - `sines.rs`: `SINES[181]`, `16384 sin(i/2 degrees)` rounded; generated in double
    precision, nearest entry to a tie is i = 94 (11982.499).
  - Palette indices a part uses must all have a `material` line (the `VoxMap` rule: an index
    the map does not decide is an error); index 0 is air.
  - `.vox` node names: `VoxFile::names: BTreeMap<u32, String>` from any node's `_name`
    attribute; `encode` writes it back. A part's `node <name>` is the transform of that name
    (exactly one), its child shape's first model.
  - `VoxText { colors, models }`, `parse`, `write`, `to_vox_file`, `from_vox_file`;
    `VoxTextError { line, message }`. Layer rows: first row is the largest y; x along the
    row; layers are z from the bottom. `to_vox_file` writes version 200, MagicaVoxel's default
    palette with each `color` over it, root transform 0, group 1, transform `2 + 2k` (named,
    at `at`) over shape `3 + 2k`. `from_vox_file` lists every index a model uses or whose colour
    differs from the default palette; a scene-graph rotation is not kept.
  - The example: `cargo run -p vxe-assets --example voxtext -- to-vox|from-vox <in> <out>`;
    by hand on a one-model file, to-vox, from-vox, to-vox gave `cmp`-identical `.vox` bytes.
