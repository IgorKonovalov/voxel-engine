## Phase 1: Clips in `vxe-entity`

- **Start commit:** `plan-0062` at bc80246 (Plan 0062 Phase 1), branch `plan-0063`, a stacked
  lane.
- **Names, plan to tree:**
  - `sample(model, rest: &Pose, clip, tick: u64) -> Pose`. `Part` has no rest offset (Plan 0062
    readings log), so the rest layout is the `t` of the rest pose's part poses; a key's `t` is
    an offset added to it, a key's `q` replaces the rest rotation; a part with no track copies
    its rest `PartPose`. The returned root is the origin, unturned.
  - `Key { tick: u32, t: [i32; 3], q: Quat }`, `Track { part: u8, keys: Vec<Key> }`,
    `Clip::new(&Model, length: u32, looped: bool, Vec<Track>) -> Result<Clip, ClipError>`.
    `ClipError::{UnsortedTrack, KeyPastLength, UnknownPart}` (the plan's three) plus
    `ZeroLength`, `EmptyTrack`, `DuplicateTrack`. Ticks in a track must strictly increase.
  - `Clip::clip_tick(tick)`: `tick % length` when looped, `min(tick, length)` otherwise.
  - Translation between keys: `(a (den - num) + b num) / den` in `i64`, truncated (toward zero).
    Rotation: `quat::nlerp`, the same weights, the second key negated when the dot is negative,
    renormalised with the existing integer `normalise`.
  - `blend(a, b, w: u16) -> Pose`: root, root rotation and every part by the same rules;
    `w` 0 and >= 256 return clones of `a` and `b`; panics on unequal part counts.
  - `Playback { clip: Arc<Clip>, start_tick: u64, rate: u32 }`, `tick_at(now) -> u64`
    (`(now - start) * rate / 256`, floor, 0 before the start), `pose(model, rest, now)`.
